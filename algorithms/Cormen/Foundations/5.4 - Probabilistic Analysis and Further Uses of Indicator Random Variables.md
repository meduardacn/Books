# 5.4 Probabilistic Analysis and Further Uses of Indicator Random Variables

This advanced section illustrates probabilistic analysis through four examples: the **birthday paradox**, **balls and bins**, **streaks** of consecutive heads in coin flips, and an **on-line variant of the hiring problem** where decisions must be made without interviewing all candidates.

## 5.4.1 The birthday paradox

How many people must be in a room before there is a 50% chance that two share a birthday? The answer is surprisingly few — fewer than half the number of days in a year.

Assume n = 365 days, ignore leap years, and assume birthdays are independent and uniformly distributed across the n days. The probability that two specified people i and j share a birthday is 1/n.

To find when *at least one* pair matches, look at the complementary event — that all k birthdays are distinct. Let Bₖ be that event. Conditional on the first k − 1 being distinct, the probability the k-th differs is (n − k + 1)/n. Iterating:

Pr{Bₖ} = 1 · (1 − 1/n) · (1 − 2/n) ⋯ (1 − (k−1)/n) ≤ e^(−k(k−1)/2n).

This is ≤ 1/2 when k(k − 1) ≥ 2n ln 2, i.e., k ≥ (1 + √(1 + (8 ln 2)n)) / 2. For n = 365, we need **k ≥ 23**. On Mars (year = 669 Martian days), it takes 31 Martians.

### Analysis using indicator random variables

Define Xᵢⱼ = I{person i and person j share a birthday} (1 ≤ i < j ≤ k). E[Xᵢⱼ] = 1/n. Let X = ΣΣ Xᵢⱼ = total number of matching pairs.

E[X] = C(k, 2) · 1/n = k(k − 1)/(2n).

When k(k − 1) ≥ 2n, the expected number of matching pairs is ≥ 1. With at least √(2n) + 1 individuals, we expect at least one matching pair. For n = 365, k = 28 gives E[X] ≈ 1.0356, so with at least 28 people we expect at least one matching pair.

The two analyses give different numerical answers but both yield Θ(√n) asymptotically.

## 5.4.2 Balls and bins

Toss identical balls into b bins (numbered 1, …, b). Tosses are independent; each ball lands in any bin with probability 1/b. The ball-tossing process is a sequence of **Bernoulli trials**. This model is useful for analyzing hashing.

**How many balls fall in a given bin?** Follows the binomial distribution b(k; n, 1/b). Expected number of balls in a given bin = n/b.

**Expected number of tosses until a given bin contains a ball?** Geometric distribution with probability 1/b; expected value is b.

**Expected number of tosses until every bin contains at least one ball?** Partition the n tosses into stages; in stage i, i − 1 bins contain balls and b − i + 1 are empty. Probability of a "hit" in stage i is (b − i + 1)/b. Expected number of tosses for b hits is:

E[n] = b · Σ 1/i (i from 1 to b) = b(ln b + O(1)).

It takes approximately **b ln b** tosses to expect all bins filled — the **coupon collector's problem**.

## 5.4.3 Streaks

Flip a fair coin n times. What is the longest streak of consecutive heads?

**Upper bound: O(lg n).** Let Aᵢₖ be the event that a streak of heads of length ≥ k begins at position i. Then Pr{Aᵢₖ} = 1/2^k. For k = 2⌈lg n⌉, Pr{Aᵢ,2⌈lg n⌉} ≤ 1/n². By Boole's inequality, the probability that any streak of length ≥ 2⌈lg n⌉ starts anywhere is < 1/n. Through more analysis, E[L] = O(lg n), where L is the longest streak.

**Lower bound: Ω(lg n).** Partition n flips into groups of ⌊(lg n)/2⌋ consecutive flips. The probability a given group is all heads is 1/2^⌊(lg n)/2⌋ ≥ 1/√n. With ⌊n / ⌊(lg n)/2⌋⌋ groups, the probability that **no** group is all heads is at most (1 − 1/√n)^… = O(1/n). So with probability 1 − O(1/n), some group is all heads, giving a streak ≥ ⌊(lg n)/2⌋.

Combining gives **E[L] = Θ(lg n)**.

A simpler approximate analysis via indicator random variables: let Xᵢₖ = I{streak of length ≥ k beginning at flip i}. X = Σ Xᵢₖ has E[X] = (n − k + 1)/2^k. For k = c lg n, E[X] = Θ(1/n^(c−1)). For large c the expected count is small; for c = 1/2 it is large. Therefore the expected longest streak is Θ(lg n).

## 5.4.4 The on-line hiring problem

A variant: we cannot interview all candidates first and cannot fire/rehire. We must, immediately after each interview, **offer the position or reject the applicant**. The goal is to balance interviewing cost against quality of the hire.

Model: after meeting applicant i, we know score(i). Strategy: interview and reject the first **k** applicants, then hire the first thereafter who scores higher than all preceding. If no such applicant appears, hire the n-th.

```
ON-LINE-MAXIMUM(k, n)
1  bestscore = -∞
2  for i = 1 to k
3      if score(i) > bestscore
4          bestscore = score(i)
5  for i = k+1 to n
6      if score(i) > bestscore
7          return i
8  return n
```

Let S be the event that we succeed in choosing the best-qualified applicant, and Sᵢ the event that we succeed when the best is the i-th interviewed. Computing carefully:

Pr{S} = (k/n) · Σ 1/(i−1) (i from k+1 to n) = (k/n) · Σ 1/i (i from k to n−1).

Approximating by integrals: (k/n)(ln n − ln k) ≤ Pr{S} ≤ (k/n)(ln(n−1) − ln(k−1)).

Maximize the lower bound by differentiating with respect to k and setting it to 0: **k = n/e**. With this k, we succeed in hiring the best-qualified applicant with probability **at least 1/e**.
