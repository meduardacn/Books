# 4.6 Proof of the Master Theorem

This section contains a proof of the master theorem (Theorem 4.1). You do not need to understand the proof in order to apply the master theorem.

The proof is in two parts:

1. **The proof for exact powers.** Analyze the master recurrence under the simplifying assumption that T(n) is defined only on exact powers of b (n = 1, b, b², …). This gives the intuition.
2. **Floors and ceilings.** Extend the analysis to all positive integers n by handling floors and ceilings.

We sometimes abuse asymptotic notation by applying it to functions defined only over exact powers of b.

## 4.6.1 The proof for exact powers

We break the analysis into three lemmas.

### Lemma 4.2

Let a ≥ 1 and b > 1 be constants, and let f(n) be a nonnegative function defined on exact powers of b. Define T(n) on exact powers of b by T(n) = Θ(1) if n = 1, T(n) = aT(n/b) + f(n) if n = b^i. Then:

> T(n) = Θ(n^(log_b a)) + Σ a^j · f(n/b^j) for j = 0 to (log_b n) − 1.

**Proof sketch.** Use the recursion tree. The tree has a^(log_b n) = n^(log_b a) leaves, each costing Θ(1), giving Θ(n^(log_b a)). The summation comes from summing the costs of the internal nodes at each depth j, each of which is a^j · f(n/b^j).

The three cases of the master theorem correspond to whether the tree's total cost is (1) dominated by costs at the leaves, (2) evenly distributed across levels, or (3) dominated by the root.

### Lemma 4.3

Let a ≥ 1, b > 1 be constants, f(n) be a nonnegative function defined on exact powers of b. Define g(n) = Σ a^j · f(n/b^j) for j = 0 to (log_b n) − 1. Then:

1. If f(n) = O(n^(log_b a − ε)) for some ε > 0, then g(n) = O(n^(log_b a)).
2. If f(n) = Θ(n^(log_b a)), then g(n) = Θ(n^(log_b a) · lg n).
3. If af(n/b) ≤ cf(n) for some c < 1 and all sufficiently large n, then g(n) = Θ(f(n)).

**Proof sketch.**

- **Case 1:** Substituting f(n) = O(n^(log_b a − ε)) yields an *increasing geometric series* bounded by n^(log_b a − ε) · O(n^ε) = O(n^(log_b a)).
- **Case 2:** Substituting f(n) = Θ(n^(log_b a)) makes every term of the sum equal: n^(log_b a) · log_b n levels.
- **Case 3:** The regularity condition makes the sum a *decreasing geometric series*, dominated by the first term f(n).

### Lemma 4.4

Combines Lemmas 4.2 and 4.3 to prove the master theorem for n = b^i (i a positive integer):

- **Case 1:** T(n) = Θ(n^(log_b a)) + O(n^(log_b a)) = Θ(n^(log_b a)).
- **Case 2:** T(n) = Θ(n^(log_b a)) + Θ(n^(log_b a) lg n) = Θ(n^(log_b a) lg n).
- **Case 3:** T(n) = Θ(n^(log_b a)) + Θ(f(n)) = Θ(f(n)) (because case 3 assumes f(n) = Ω(n^(log_b a + ε))).

## 4.6.2 Floors and ceilings

The master recurrence is technically T(n) = aT(⌊n/b⌋) + f(n) or T(n) = aT(⌈n/b⌉) + f(n). The proof extends the recursion tree to track repeated applications of ⌈n/b⌉:

n, ⌈n/b⌉, ⌈⌈n/b⌉/b⌉, …

Defining nⱼ = n if j = 0, ⌈nⱼ₋₁/b⌉ otherwise, one can show that nⱼ ≤ n/b^j + b/(b − 1). At depth ⌊log_b n⌋, the problem size is at most a constant, so the tree depth is roughly log_b n.

T(n) = Θ(n^(log_b a)) + Σ a^j · f(nⱼ) for j = 0 to ⌊log_b n⌋ − 1.

The same approach as Lemma 4.3 evaluates this summation. The key step shows f(nⱼ) = O((n/b^j)^(log_b a)), so the proof of case 2 carries over. Cases 1 and 3 use analogous (slightly more intricate) arguments.

The proof of the lower bounds is similar to the proof of the upper bounds. After this analysis, the master theorem holds for all positive integers n.
