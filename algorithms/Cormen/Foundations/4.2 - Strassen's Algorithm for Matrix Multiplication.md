# 4.2 Strassen's Algorithm for Matrix Multiplication

## Square matrix multiplication

For n × n matrices A = (aᵢⱼ) and B = (bᵢⱼ), the product C = A · B has cᵢⱼ = Σ aᵢₖ · bₖⱼ (sum over k).

The straightforward algorithm:

```
SQUARE-MATRIX-MULTIPLY(A, B)
1  n = A.rows
2  let C be a new n × n matrix
3  for i = 1 to n
4      for j = 1 to n
5          cᵢⱼ = 0
6          for k = 1 to n
7              cᵢⱼ = cᵢⱼ + aᵢₖ · bₖⱼ
8  return C
```

Three nested loops give **Θ(n³)** time.

One might think Ω(n³) is necessary since the definition requires that many multiplications. **Not so.** Strassen's recursive algorithm runs in Θ(n^lg 7) time. Since lg 7 ≈ 2.807, this is O(n^2.81), asymptotically better than Θ(n³).

## A simple divide-and-conquer algorithm

For simplicity, assume n is an exact power of 2. Partition A, B, C into four n/2 × n/2 submatrices:

A = ((A₁₁ A₁₂)(A₂₁ A₂₂)), similarly for B and C. Then C = A · B yields four equations:

- C₁₁ = A₁₁ · B₁₁ + A₁₂ · B₂₁
- C₁₂ = A₁₁ · B₁₂ + A₁₂ · B₂₂
- C₂₁ = A₂₁ · B₁₁ + A₂₂ · B₂₁
- C₂₂ = A₂₁ · B₁₂ + A₂₂ · B₂₂

These require **8 multiplications** of n/2 × n/2 matrices plus 4 additions. Using index calculations (no copying), the recurrence is:

> T(n) = 8T(n/2) + Θ(n²)

The master method gives T(n) = **Θ(n³)** — no asymptotic improvement over straightforward multiplication.

The reason: although Θ-notation subsumes the constant 4 in front of the n² additions, **recursive notation T(n/2) does not subsume the constant 8** in front. The factor 8 makes the recursion tree very bushy, leading to n³ work.

## Strassen's method

Strassen's key idea is to make the recursion tree slightly less bushy: perform **only 7** recursive multiplications of n/2 × n/2 matrices instead of 8. This costs additional matrix additions, but only a constant number, which Θ-notation subsumes.

The method has four steps:

1. **Divide** the input matrices A, B, and output C into n/2 × n/2 submatrices. Θ(1) by index calculations.
2. **Create 10 matrices** S₁, …, S₁₀, each n/2 × n/2 and each a sum or difference of two submatrices from step 1. Θ(n²) time.
3. **Recursively compute 7 matrix products** P₁, …, P₇ using the submatrices and the Sᵢ matrices.
4. **Compute C's submatrices** C₁₁, C₁₂, C₂₁, C₂₂ by adding and subtracting various combinations of the Pᵢ. Θ(n²) time.

This yields the recurrence:

> T(n) = 7T(n/2) + Θ(n²)

which by the master method has solution **T(n) = Θ(n^lg 7) ≈ O(n^2.81)** — asymptotically faster than SQUARE-MATRIX-MULTIPLY.

### The 10 Sᵢ matrices (step 2)

S₁ = B₁₂ − B₂₂; S₂ = A₁₁ + A₁₂; S₃ = A₂₁ + A₂₂; S₄ = B₂₁ − B₁₁; S₅ = A₁₁ + A₂₂; S₆ = B₁₁ + B₂₂; S₇ = A₁₂ − A₂₂; S₈ = B₂₁ + B₂₂; S₉ = A₁₁ − A₂₁; S₁₀ = B₁₁ + B₁₂.

### The 7 Pᵢ products (step 3)

- P₁ = A₁₁ · S₁ = A₁₁ · B₁₂ − A₁₁ · B₂₂
- P₂ = S₂ · B₂₂ = A₁₁ · B₂₂ + A₁₂ · B₂₂
- P₃ = S₃ · B₁₁ = A₂₁ · B₁₁ + A₂₂ · B₁₁
- P₄ = A₂₂ · S₄ = A₂₂ · B₂₁ − A₂₂ · B₁₁
- P₅ = S₅ · S₆ = A₁₁ · B₁₁ + A₁₁ · B₂₂ + A₂₂ · B₁₁ + A₂₂ · B₂₂
- P₆ = S₇ · S₈ = A₁₂ · B₂₁ + A₁₂ · B₂₂ − A₂₂ · B₂₁ − A₂₂ · B₂₂
- P₇ = S₉ · S₁₀ = A₁₁ · B₁₁ + A₁₁ · B₁₂ − A₂₁ · B₁₁ − A₂₁ · B₁₂

### The 4 Cᵢⱼ combinations (step 4)

- C₁₁ = P₅ + P₄ − P₂ + P₆
- C₁₂ = P₁ + P₂
- C₂₁ = P₃ + P₄
- C₂₂ = P₅ + P₁ − P₃ − P₇

Expanding shows each equation matches the standard formulas. Strassen has traded one multiplication for a constant number of matrix additions — and that trade leads to a lower asymptotic running time.
