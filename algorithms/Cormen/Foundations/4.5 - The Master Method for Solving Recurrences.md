# 4.5 The Master Method for Solving Recurrences

The **master method** provides a "cookbook" method for solving recurrences of the form:

> T(n) = aT(n/b) + f(n)

where a ≥ 1 and b > 1 are constants and f(n) is an asymptotically positive function. To use the master method, memorize three cases — then many recurrences can be solved easily, often without pencil and paper.

Such a recurrence describes the running time of an algorithm that divides a problem of size n into **a** subproblems, each of size **n/b**, where a and b are positive constants. The a subproblems are solved recursively, each in time T(n/b). The function f(n) encompasses the cost of dividing the problem and combining the results. For example, Strassen's algorithm has a = 7, b = 2, and f(n) = Θ(n²).

We normally omit the floor and ceiling functions; this does not affect the asymptotic behavior.

## The master theorem

**Theorem 4.1 (Master theorem):** Let a ≥ 1 and b > 1 be constants, let f(n) be a function, and let T(n) be defined on the nonnegative integers by T(n) = aT(n/b) + f(n), where n/b means either ⌊n/b⌋ or ⌈n/b⌉. Then T(n) has the following asymptotic bounds:

1. If **f(n) = O(n^(log_b a − ε))** for some constant ε > 0, then T(n) = **Θ(n^(log_b a))**.
2. If **f(n) = Θ(n^(log_b a))**, then T(n) = **Θ(n^(log_b a) · lg n)**.
3. If **f(n) = Ω(n^(log_b a + ε))** for some constant ε > 0, **and** if af(n/b) ≤ cf(n) for some constant c < 1 and all sufficiently large n, then T(n) = **Θ(f(n))**.

## Intuition

In each case we compare f(n) with n^(log_b a):

- Whichever of the two is **larger** determines the solution.
- If both are the **same size** (case 2), multiply by a logarithmic factor.

## Technicalities

- In case 1, f(n) must be **polynomially smaller** than n^(log_b a) — smaller by a factor of n^ε.
- In case 3, f(n) must be **polynomially larger** AND satisfy the "regularity" condition af(n/b) ≤ cf(n). This holds for most polynomially bounded functions encountered.
- The three cases do not cover all possibilities. Gaps exist between cases 1 and 2 (f(n) smaller than n^(log_b a) but not polynomially) and between 2 and 3 (larger but not polynomially). If f(n) falls in such a gap, or the regularity condition fails, the master method does not apply.

## Examples

**T(n) = 9T(n/3) + n.** a = 9, b = 3, f(n) = n, n^(log_b a) = n². Since f(n) = O(n^(2−1)), case 1 with ε = 1. **T(n) = Θ(n²)**.

**T(n) = T(2n/3) + 1.** a = 1, b = 3/2, f(n) = 1, n^(log_b a) = n⁰ = 1. f(n) = Θ(1) = Θ(n^(log_b a)), so case 2. **T(n) = Θ(lg n)**.

**T(n) = 3T(n/4) + n lg n.** a = 3, b = 4, f(n) = n lg n, n^(log_b a) = n^(log_4 3) = O(n^0.793). f(n) = Ω(n^(log_4 3 + ε)) for some ε ≈ 0.2. Regularity: 3(n/4) lg(n/4) ≤ (3/4)n lg n. Case 3. **T(n) = Θ(n lg n)**.

**T(n) = 2T(n/2) + n lg n.** Master method **does not apply**. a = 2, b = 2, f(n) = n lg n, n^(log_b a) = n. f(n) is asymptotically larger than n but **not polynomially larger** — the ratio is lg n, asymptotically less than n^ε for any ε > 0. Falls into the gap between cases 2 and 3.

## Applying the master method to recurrences we've seen

- **Merge sort / maximum-subarray:** T(n) = 2T(n/2) + Θ(n). a = 2, b = 2, n^(log_b a) = n. Case 2: **T(n) = Θ(n lg n)**.
- **Simple divide-and-conquer matrix multiplication:** T(n) = 8T(n/2) + Θ(n²). a = 8, b = 2, n^(log_b a) = n³. n³ is polynomially larger than n². Case 1: **T(n) = Θ(n³)**.
- **Strassen's algorithm:** T(n) = 7T(n/2) + Θ(n²). a = 7, b = 2, n^(log_b a) = n^(lg 7). f(n) = O(n^(lg 7 − ε)) for ε ≈ 0.8. Case 1: **T(n) = Θ(n^(lg 7))**.
