# 5.2 Indicator Random Variables

## Definition

**Indicator random variables** provide a convenient method for converting between probabilities and expectations. Given a sample space S and an event A, the indicator random variable I{A} associated with A is:

> I{A} = 1 if A occurs; 0 if A does not occur.

## Simple example: coin flip

Sample space S = {H, T}, Pr{H} = Pr{T} = 1/2. Define X_H = I{H}. Then the expected number of heads in one flip is:

E[X_H] = E[I{H}] = 1 · Pr{H} + 0 · Pr{T} = 1/2.

## Lemma 5.1

Given a sample space S and an event A, let X_A = I{A}. Then E[X_A] = Pr{A}.

**Proof.** By definitions of indicator random variable and expected value, E[X_A] = 1·Pr{A} + 0·Pr{Ā} = Pr{A}.

## Why indicator variables are useful

Although they may seem cumbersome for a single flip, indicator random variables are powerful for analyzing **repeated trials**. They give a simple way to compute the expected number of times an event occurs.

**Example: n coin flips.** Let Xᵢ = I{i-th flip is heads}. The total number of heads X = Σ Xᵢ. Then:

E[X] = E[Σ Xᵢ] = Σ E[Xᵢ] = Σ Pr{Xᵢ = 1} = Σ 1/2 = n/2.

**Linearity of expectation** makes the use of indicator random variables a powerful analytical technique — it applies even when there is dependence among the random variables.

## Analysis of the hiring problem using indicator random variables

Compute the expected number of times we hire a new office assistant, assuming candidates arrive in random order.

Let X be the random variable for the number of times we hire. Define n indicator random variables:

Xᵢ = I{candidate i is hired} = 1 if candidate i is hired, 0 otherwise.

Then X = X₁ + X₂ + ⋯ + Xₙ. By Lemma 5.1, E[Xᵢ] = Pr{candidate i is hired}.

**Key observation:** Candidate i is hired exactly when candidate i is better than each of candidates 1 through i−1. Since the candidates arrive in random order, any of the first i candidates is equally likely to be best-qualified. Thus candidate i has a probability of **1/i** of being the best so far — and so a probability of 1/i of being hired.

Therefore E[Xᵢ] = 1/i, and:

E[X] = Σ E[Xᵢ] = Σ 1/i (i from 1 to n) = ln n + O(1).

Even though we interview n people, on average we hire only approximately **ln n** of them.

## Lemma 5.2

Assuming candidates are presented in random order, HIRE-ASSISTANT has an average-case total hiring cost of **O(cₕ ln n)**.

**Proof.** The bound follows from the definition of hiring cost and the result that the expected number of hires is approximately ln n.

The average-case hiring cost O(cₕ ln n) is a significant improvement over the worst-case hiring cost O(cₕn).
