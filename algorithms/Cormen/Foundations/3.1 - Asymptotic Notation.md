# 3.1 Asymptotic Notation

The notations used to describe the asymptotic running time of an algorithm are defined in terms of functions whose domains are the set of natural numbers ℕ = {0, 1, 2, …}. They are convenient for describing the worst-case running-time function T(n), which is usually defined only on integer input sizes. Asymptotic notation is sometimes "abused" — extended to the reals or restricted to a subset of ℕ — but the precise meaning must always be understood.

## Asymptotic notation, functions, and running times

Asymptotic notation is used primarily to describe the running times of algorithms (e.g., insertion sort's worst case is Θ(n²)). It actually applies to **functions** — writing Θ(n²) abstracts away details of an² + bn + c. It can also apply to functions characterizing space, or even functions unrelated to algorithms.

When applied to running times, we must understand which one — worst-case, best-case, or all inputs. Asymptotic notations exist that suit each.

## Θ-notation (asymptotically tight bound)

For a given function g(n):

> Θ(g(n)) = { f(n) : there exist positive constants c₁, c₂, n₀ such that 0 ≤ c₁g(n) ≤ f(n) ≤ c₂g(n) for all n ≥ n₀ }.

f(n) belongs to Θ(g(n)) if it is "sandwiched" between c₁g(n) and c₂g(n) for sufficiently large n. We write **f(n) = Θ(g(n))** (abusing equality). g(n) is an **asymptotically tight bound** for f(n).

Every member of Θ(g(n)) must be **asymptotically nonnegative** — nonnegative for sufficiently large n.

For any polynomial p(n) = Σaᵢnⁱ with aₐ > 0, we have p(n) = Θ(n^d).
Any constant function is Θ(n⁰) = Θ(1).

## O-notation (asymptotic upper bound)

When we have only an upper bound:

> O(g(n)) = { f(n) : there exist positive constants c and n₀ such that 0 ≤ f(n) ≤ cg(n) for all n ≥ n₀ }.

f(n) = Θ(g(n)) implies f(n) = O(g(n)). Θ-notation is stronger than O-notation. Set-theoretically, Θ(g(n)) ⊆ O(g(n)).

A quadratic an² + bn + c is in O(n²), but so is any linear an + b. In this book, f(n) = O(g(n)) merely claims that some constant multiple of g(n) is an asymptotic upper bound, with no claim about how tight it is.

## Ω-notation (asymptotic lower bound)

> Ω(g(n)) = { f(n) : there exist positive constants c and n₀ such that 0 ≤ cg(n) ≤ f(n) for all n ≥ n₀ }.

**Theorem 3.1:** For any two functions f(n) and g(n), we have f(n) = Θ(g(n)) if and only if f(n) = O(g(n)) and f(n) = Ω(g(n)).

When we say the running time (no modifier) of an algorithm is Ω(g(n)), we mean that *no matter what input of size n is chosen*, the running time is at least a constant times g(n) for sufficiently large n. The running time of insertion sort therefore belongs to both Ω(n) and O(n²).

## Asymptotic notation in equations and inequalities

When asymptotic notation stands alone on the right-hand side, the "=" is set membership: n ∈ O(n²).
When asymptotic notation appears inside a formula, it stands for some anonymous function we don't care to name. For example, 2n² + 3n + 1 = 2n² + Θ(n) means 2n² + 3n + 1 = 2n² + f(n) for some f(n) ∈ Θ(n).

Such usage helps eliminate inessential detail, as in T(n) = 2T(n/2) + Θ(n).

When asymptotic notation appears on the left-hand side of an equation, the rule is: *No matter how the anonymous functions are chosen on the left, there is a way to choose the anonymous functions on the right to make the equation valid.* So the right side provides a coarser level of detail.

## o-notation (asymptotic upper bound that is not tight)

> o(g(n)) = { f(n) : for any positive constant c > 0, there exists a constant n₀ > 0 such that 0 ≤ f(n) < cg(n) for all n ≥ n₀ }.

E.g., 2n = o(n²) but 2n² ≠ o(n²). Equivalently, lim (n→∞) f(n)/g(n) = 0.

## ω-notation (asymptotic lower bound that is not tight)

By analogy: ω is to Ω as o is to O. f(n) ∈ ω(g(n)) if and only if g(n) ∈ o(f(n)). Equivalently, lim (n→∞) f(n)/g(n) = ∞.

## Comparing functions

Many relational properties of real numbers carry over to asymptotic comparisons (assuming f, g are asymptotically positive):

- **Transitivity** holds for Θ, O, Ω, o, and ω.
- **Reflexivity** holds for Θ, O, Ω.
- **Symmetry:** f(n) = Θ(g(n)) iff g(n) = Θ(f(n)).
- **Transpose symmetry:** f = O(g) iff g = Ω(f); f = o(g) iff g = ω(f).

By analogy: O ↔ ≤, Ω ↔ ≥, Θ ↔ =, o ↔ <, ω ↔ >. f(n) is **asymptotically smaller** than g(n) if f = o(g), and **asymptotically larger** if f = ω(g).

**Trichotomy** (a < b, a = b, or a > b) does **not** carry over: two functions need not be asymptotically comparable. For example, n and n^(1+sin n) are not comparable since the exponent oscillates between 0 and 2.
