# 4.3 The Substitution Method for Solving Recurrences

The **substitution method** for solving recurrences comprises two steps:

1. **Guess** the form of the solution.
2. **Use mathematical induction** to find the constants and show that the solution works.

We substitute the guessed solution for the function when applying the inductive hypothesis to smaller values — hence the name. The method is powerful, but only when one can guess the form of the answer.

The method can establish either upper or lower bounds.

## Example

Determine an upper bound on T(n) = 2T(⌊n/2⌋) + n. Guess T(n) = O(n lg n) — i.e., T(n) ≤ cn lg n for some c > 0. Assume the bound holds for all positive m < n, so T(⌊n/2⌋) ≤ c⌊n/2⌋ lg(⌊n/2⌋). Then:

T(n) ≤ 2(c⌊n/2⌋ lg(⌊n/2⌋)) + n ≤ cn lg(n/2) + n = cn lg n − cn lg 2 + n = cn lg n − cn + n ≤ cn lg n

as long as c ≥ 1.

## Boundary conditions

Mathematical induction must show the solution holds for the **boundary conditions**. Typically, we choose c large enough so the bound T(n) ≤ cn lg n holds for the base cases. Sometimes T(1) = 1 yields T(1) ≤ c · 1 · lg 1 = 0, which fails. The fix: since asymptotic notation only requires the bound for n ≥ n₀ (with n₀ a constant we choose), drop n = 1 from the inductive proof and use n = 2 and n = 3 instead.

## Making a good guess

There is **no general way** to guess correct solutions. Some heuristics:

- If a recurrence is similar to one you have seen, guess a similar solution. Example: T(n) = 2T(⌊n/2⌋ + 17) + n. The +17 cannot substantially affect the solution since both halves are ≈ n/2; guess T(n) = O(n lg n).
- Prove **loose upper and lower bounds**, then narrow them. For instance, start with T(n) = Ω(n) and T(n) = O(n²), and gradually converge on Θ(n lg n).

## Subtleties

Sometimes the inductive hypothesis is not strong enough to prove the detailed bound. The fix is often counterintuitive: **subtract a lower-order term**.

Example: T(n) = T(⌊n/2⌋) + T(⌈n/2⌉) + 1. Guess T(n) = O(n) with T(n) ≤ cn. Substituting gives T(n) ≤ cn + 1, which does not imply T(n) ≤ cn.

Strengthen the guess: T(n) ≤ cn − d (where d ≥ 0). Substituting:

T(n) ≤ (c⌊n/2⌋ − d) + (c⌈n/2⌉ − d) + 1 = cn − 2d + 1 ≤ cn − d as long as d ≥ 1.

The proof of the **weaker** upper bound goes through because the proof must use the same weaker bound inductively — leaving room for the +1.

## Avoiding pitfalls

It's easy to misuse asymptotic notation. For example, "proving" T(n) ≤ 2(c⌊n/2⌋) + n ≤ cn + n = O(n) is **wrong** because we have not proved the exact form of the inductive hypothesis (T(n) ≤ cn). Always explicitly prove T(n) ≤ cn when you want to show T(n) = O(n).

## Changing variables

A little algebraic manipulation can make an unfamiliar recurrence look like a familiar one. Example: T(n) = 2T(⌊√n⌋) + lg n.

Let m = lg n (so n = 2^m): T(2^m) = 2T(2^(m/2)) + m. Renaming S(m) = T(2^m):

> S(m) = 2S(m/2) + m

which is like the standard merge-sort recurrence with solution S(m) = O(m lg m). Changing back: T(n) = T(2^m) = S(m) = O(m lg m) = **O(lg n · lg lg n)**.
